🎯 Tujuan Pembelajaran

Setelah belajar

Setelah menyelesaikan pembelajaran, murid diharapkan mampu:

1
Menjelaskan konsep algoritma
Mengidentifikasi algoritma sebagai urutan langkah logis untuk menyelesaikan masalah.
2
Menganalisis instruksi
Menemukan ketidakjelasan, urutan salah, atau langkah yang tidak diperlukan.
3
Merepresentasikan algoritma
Menggunakan narasi, pseudocode, dan flowchart sederhana.
4
Menguji dan memperbaiki
Melakukan dry run dan memperbaiki algoritma berdasarkan hasil uji.

💡 Apersepsi

“Kalau membuat mi instan, apakah urutan langkah boleh dibolak-balik?” 🍜

Bayangkan temanmu hanya mengikuti instruksi tertulis. Jika kamu menulis “masukkan bumbu” sebelum menjelaskan kapan dan bagaimana menyiapkan mi, apakah hasilnya pasti sama?

📚 Materi Interaktif

Ringkas • Bermakna
Konsep
Algoritma

Serangkaian langkah yang logis, terurut, jelas, dan terbatas untuk menyelesaikan suatu masalah atau mencapai tujuan.

Contoh: algoritma mengirim tugas digital → buka LMS → login → pilih kelas → unggah file → periksa file → kirim.
Ciri penting

🧩 4 pertanyaan penguji

  • Apakah langkahnya jelas?
  • Apakah urutannya benar?
  • Apakah dapat dilaksanakan?
  • Apakah prosesnya berhenti?

🔁 Representasi Algoritma

📝 Deskripsi

Ditulis dengan bahasa sehari-hari yang terstruktur.

⌨️ Pseudocode

Instruksi semi-formal agar mudah diterjemahkan ke program.

🔷 Flowchart

Diagram dengan simbol untuk menunjukkan alur proses.

Contoh pseudocode: menentukan bilangan genap

MULAI
INPUT n
IF n MOD 2 = 0 THEN
  TULIS "Genap"
ELSE
  TULIS "Ganjil"
END IF
